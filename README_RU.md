# Call of Duty 3 — русский перевод от Savkin

Русский перевод текста для **PlayStation 2, PlayStation 3 и Xbox 360**, версия 1.0.

Переведены меню и настройки, описания и цели миссий, игровые подсказки, субтитры диалогов и сюжетных роликов. Весь перевод прошёл **двойную редактуру**: выверены смысл, терминология, имена персонажей и естественность реплик. Шрифты, обозначения кнопок и переносы текста адаптированы для каждой платформы. Озвучка сохранена на английском языке.

## Скачать

[Скачать установщик и патчи для Windows](https://github.com/alekszverr-jpg/cod3-russian-translation/releases/tag/v1.0)

В релизе приложены архив `Call_of_Duty_3_RU_Savkin_v1.0_Installer_Windows.zip` и его контрольная сумма SHA-256. В одном архиве находятся патчи для трёх платформ. Нужна собственная поддерживаемая исходная игра; полных игр в репозитории и архиве нет.

Версия опубликована как **Pre-release**: установка и контрольные суммы проверены для всех трёх платформ, но контрольный игровой запуск новых PS3/Xbox-сборок ещё требуется.

## Поддерживаемые исходники

| Платформа | Исходная игра | Результат |
|---|---|---|
| PS2 | Английский ISO, SLUS-21426 (USA) | Отдельный ISO |
| PS3 | Оригинальная папка BLES-00016 с PS3_GAME | Отдельная папка игры |
| Xbox 360 | Распакованная английская игра с default.xex, Title ID 415607E1 | Отдельная папка игры |

Xbox ISO и GOD перед установкой нужно извлечь в обычную папку игры. Старые сторонние русификации и уже изменённые файлы не подходят. Установщик проверяет точные размеры и SHA-256: одного совпадения названия или кода игры недостаточно. Поддерживаемые хеши перечислены в `manifest.json` внутри архива установщика.

## Установка

1. Полностью распакуйте архив установщика. Сохраните рядом с программой `manifest.json`, `patches/` и `third_party/`.
2. Запустите `COD3_RU_Installer.exe` в 64-разрядной Windows 10/11. Python не нужен.
3. Выберите платформу и исходную игру. При желании нажмите «Проверить исходник».
4. Укажите **новый** файл ISO или новую папку результата и нажмите «Установить перевод».
5. Дождитесь завершения проверки готовой игры.

Установщик сохраняет исходную игру и проверяет целостность готовой сборки. Существующий результат не перезаписывается. При прерывании установки неполную копию можно удалить и повторить установку в новый путь. Сохранения и настройки эмуляторов установщик не меняет.

## Запуск и проверка

- **PS2:** открыть готовый ISO в PCSX2. Пользователь подтвердил проверку PS2-сборки на реальной приставке и работу мультиплеера.
- **PS3:** добавить готовую папку игры в RPCS3. Запуск проверен на PS3 CECH-2508A с CFW 4.93 через webMAN. Работа на HEN не проверена.
- **Xbox 360:** открыть `default.xex` в Xenia. Обновлённые исполняемые файлы проверены в Xenia. Работа на настоящей Xbox 360 пока не проверена.

После замены сборки полностью перезапустите игру: сохранённое состояние эмулятора может содержать старые ресурсы. Полное прохождение всех трёх версий не заявляется. DLC в выпуск не входят; их перевод не поддерживается этим комплектом.


## Исходный код и лицензии

В репозитории находятся исходники установщика, `Build.ps1` и документация. Для сборки запустите `Build.ps1`; для работы программы нужны манифест, патчи и xdelta3 из релизного архива.

Код установщика в `src/` распространяется по MIT ([LICENSE-INSTALLER.txt](LICENSE-INSTALLER.txt)). Эта лицензия не распространяется на игру и перевод. xdelta3 3.1.0 вызывается отдельной программой; её лицензия GPLv2 и соответствующие исходники включены в архив установщика. Подробнее: [THIRD_PARTY.md](THIRD_PARTY.md). Полных игровых файлов, образов, BIOS, ключей и эмуляторов здесь нет.
